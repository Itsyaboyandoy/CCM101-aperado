# ☁️ Mission Reflection

After completing this cloud computing mission, the cloud platform that impressed me the most is **Amazon Web Services (AWS)**. I was impressed by the large number of services it offers and how it can support different types of businesses, from small startups to large companies. AWS also provides flexible and scalable resources that can adjust depending on the needs of an organization.

AWS, Microsoft Azure, and Google Cloud Platform (GCP) have many similarities. All three provide cloud services such as virtual machines, storage, databases, networking, security, and identity management. They also allow businesses to scale their resources, manage services through web-based consoles, and run applications without needing to maintain all physical hardware themselves.

Business requirements greatly influence cloud platform selection because every organization has different needs, budgets, and existing technologies. For example, **Microsoft Azure** is a good choice for an organization that already uses Microsoft products, while **Google Cloud Platform (GCP)** is suitable for companies focused on Artificial Intelligence, Machine Learning, and Kubernetes. **AWS** can be a good choice for businesses that need many different cloud services and scalability.

Acting as a **Cloud Solutions Consultant** taught me that choosing a cloud platform is not simply about selecting the most popular provider. I learned that I need to understand the client's goals, budget, existing systems, workload, and future growth before recommending a platform.

Finally, my **GitHub Cloud Computing Portfolio** has improved because it now contains organized research, comparisons, recommendations, service mappings, and Linux investigation results. Completing this mission helped me understand the major cloud platforms better and gave me practical knowledge that I can use in future IT projects.
