# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

I believe that **compute resources** are one of the most important components of cloud infrastructure because they provide the processing power required to run applications, services, and workloads. Without compute resources, other components such as storage and networking would not be able to perform useful tasks. The CPU and memory available in a cloud server allow applications and services to execute efficiently.

## 2. How does Linux support cloud computing?

Linux plays an important role in cloud computing because it provides a stable, flexible, and efficient operating system for servers and cloud environments. During this laboratory, I used Ubuntu Linux through the KillerCoda Playground to investigate system resources using command-line tools. Linux allows cloud engineers to manage servers, inspect hardware and software resources, configure networks, manage files, and automate tasks using Bash commands.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it provides a clear record of the infrastructure design, configurations, resources, and decisions made before deployment. Proper documentation helps cloud engineers understand the system, identify potential problems, maintain the infrastructure, and troubleshoot issues. It also makes it easier for other team members or clients to understand how the environment is organized.

## 4. What new skills did you learn during this laboratory activity?

I learned how to investigate a Linux cloud environment using commands such as `lsb_release`, `uname`, `lscpu`, `nproc`, `free`, `df`, `hostname`, and `hostname -I`. I also improved my skills in Git, GitHub, Markdown documentation, cloud infrastructure analysis, and comparing AWS, Microsoft Azure, and Google Cloud services.

## 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio has become more organized and professional after completing this laboratory. I added structured documentation, infrastructure investigation results, cloud component analysis, cloud provider comparisons, screenshots, and a reflection. This activity also helped me demonstrate practical Linux, Git, GitHub, and cloud computing skills rather than only presenting theoretical information.

## Conclusion

This laboratory helped me understand that successful cloud engineering requires more than simply deploying resources. It also requires investigation, planning, documentation, organization, and continuous learning.
